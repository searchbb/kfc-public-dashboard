# NVIDIA Nemotron 以开放式自然语言证明流程斩获 IMO 金牌

[p002]
NVIDIA researchers published an open pipeline that post-trains Nemotron 3 Ultra into specialist math-reasoning agents, scoring 30/42 at IMO 2026 for gold-medal performance using only natural-language proofs — and released the full stack including checkpoints, data, code, and a new 200-problem benchmark.
