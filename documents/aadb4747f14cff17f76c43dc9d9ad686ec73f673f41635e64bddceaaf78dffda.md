[p005]
Stripe、Visa、万事达，这三家加起来处理了全球大半刷卡交易的公司，据报正在联手筹建一个稳定币平台，连 Coinbase 都在考虑加入。

[p007]
[p006]
这件事的诡异之处在于：**面对稳定币的"威胁"，可它们不但没有围剿，反而要自己下场介入。**

[p008]
[p007]
几乎同一时间，万事达推出了一个叫"**Agent Pay for Machines** "的东西，首批拉上了 Adyen、Ant International、Coinbase、Stripe、Cloudflare 等 30 多家公司。

[p009]
[p008]
布局另一个听起来非常科幻的趋势：**未来是机器替机器付款，一秒钟内完成成千上万笔微交易。**

[p010]
[p009]
![Mastercard Agent Pay for Machines](assets/%E6%94%AF%E4%BB%98%E5%B7%A8%E5%A4%B4%E8%BF%9E%E5%A4%9C%E7%BB%93%E7%9B%9F%EF%BC%9A%E4%B8%80%E5%9C%BA%E6%B2%A1%E4%B8%8A%E5%A4%B4%E6%9D%A1%E7%9A%84%E9%87%91%E8%9E%8D%E5%8F%98%E5%A4%A9%EF%BD%9C%E7%9B%B4%E6%92%AD%E9%A2%84%E5%91%8A-befb249fcf/02-image.png) Mastercard Agent Pay for Machines

[p011]
[p010]
如果你只盯着这些孤立新闻，会觉得它们互相矛盾、毫无头绪；但把它们放进同一张图里，会发现它们其实在回答同一个问题：

[p012]
[p011]
**当 AI Agent 开始替人花钱、当稳定币开始接受支付架，谁是下一代金融的底座？**

[p013]
[p012]
#  稳定币不是终局，底座之争才刚开始

[p014]
[p013]
很多人把这一轮简单理解成"稳定币又火了""币圈行情要回来了"，这恰恰错过了最底层的变革趋势。

[p015]
[p014]
**过去十年，手机支付、二维码、实时转账解决的是"人怎么更方便地付款"。**

[p016]
[p015]
现在的新问题完全不同：Agent 如何被授权花钱？API、数据、模型怎么按次收费？稳定币、银行存款、短期美债怎么变成可编程的现金和资产？

[p017]
[p016]
因为这一次的主战场，已经从"谁发币、谁市值大"，上移到了一个更隐蔽、也更值钱的层面：**当前台的数字支付完成，后台的数字金融/经济迁移开始势不可挡** 。

[p018]
[p017]
# 旧金融没有退场，新势力成了追赶者

[p019]
[p018]
举几个例子你就明白这场暗战有多激烈：

[p020]
[p019]
去年，王煜全在前哨科技特训营中提醒大家，**所谓的RWA，也就是现实资产代币化大多都是炒作，真正值得关注的是美债、美股这里资产的新迁移** 。

[p021]
[p020]
当时全球著名的资管公司贝莱德在代币化美债领域还保持领先，今年稳定币公司 Circle 的产品已经完成反超。

[p022]
[p021]
![Image](assets/%E6%94%AF%E4%BB%98%E5%B7%A8%E5%A4%B4%E8%BF%9E%E5%A4%9C%E7%BB%93%E7%9B%9F%EF%BC%9A%E4%B8%80%E5%9C%BA%E6%B2%A1%E4%B8%8A%E5%A4%B4%E6%9D%A1%E7%9A%84%E9%87%91%E8%9E%8D%E5%8F%98%E5%A4%A9%EF%BD%9C%E7%9B%B4%E6%92%AD%E9%A2%84%E5%91%8A-befb249fcf/03-image.png)RWA产品资产规模排名（6月15日）

[p023]
[p022]
另一边，Meta 开始借道 Stripe 给创作者发美元稳定币。西联、MoneyGram 这些老牌汇款公司，正把业务搬到链上。

[p024]
[p023]
**每一条单独看都是"行业新闻"。**

[p025]
[p024]
连起来看，是一个清晰的方向：**旧金融巨头通过合纵连横，全力反扑；新金融势力有样学样，加速金融** 。

[p026]
[p025]
那么问题来了，**在这张即将颠覆的金融地图上，真实的变革趋势是什么样的？**

[p027]
[p026]
当 Agent 成为新的交易主体，Visa、万事达、Coinbase、Circle、Stripe、Shopify 各自在抢什么位置？

[p028]
[p027]
RWA经历炒作之后，真正剩下哪些又价值的东西？

[p029]
[p028]
这些问题的答案，不在任何一条单独的新闻里。它需要将产业全局拼在一起，才能看清这盘棋的全貌。

[p030]
[p029]
# 站在产业全局，看懂未来趋势

[p031]
[p030]
本周前哨科技特训营，王煜全就会和你深入探讨这轮金融变革的趋势。

[p032]
[p031]
我们不讲币价，不荐代币，不追短线情绪。

[p033]
[p032]
**这次我们一起扫描20+金融支付前沿企业，完成几个产业级判断：**

[p034]
[p033]
从 Visa、万事达、Stripe、Coinbase、Circle、Shopify、Google、AWS 这些公司的真实布局出发，拆解稳定币、RWA、Agent 支付背后那套正在成形的"下一代金融基础设施"。

[p035]
[p034]
**让我们一同穿越金融变革的复杂图景，一起看清哪些公司是对手、哪些公司是盟友，了解哪些是真机会、哪些是伪命题。**

[p036]
[p035]
提前一步，走在未来趋势之上。
