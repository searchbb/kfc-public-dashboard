[p001]
# Stripe 70 亿美元买下 OpenRouter ：三个月估值翻 5 倍，最中立的 AI 中转站还能中立多久？

[p002]
作者：克洛德，深潮 TechFlow

[p003]
深潮导读：8 月 16 日，Bloomberg 与 TechCrunch 双源确认，Stripe 以超过 70 亿美元的价格收购 AI 模型路由平台 OpenRouter。三个月前这家公司 B 轮估值才 13 亿美元。OpenRouter 是开发者最常用的「一个接口连所有模型」的中转层，也是 AI 圈公认的「中立」代名词。现在它归了一家靠手续费赚钱的支付公司，开发者最看重的中立性，第一次有了明确的价签。

[p004]
8 月 16 日，Bloomberg 援引知情人士报道，Stripe 已就收购 OpenRouter 达成协议，交易金额超过 70 亿美元。TechCrunch 跟进确认，Stripe 发言人给出的回应是「不对谣言或猜测发表评论」。这笔交易如果完成，将是 AI 基础设施领域金额最大的收购之一，而双方从「服务商和客户」变成「收购方和被收购方」，只用了一个季度。

[p005]
三个月估值翻 5 倍：13 亿的 B 轮，70 亿的成交价

[p006]
今年 5 月 28 日，OpenRouter 宣布完成 1.13 亿美元 B 轮融资，投后估值约 13 亿美元，领投方是 Alphabet 的增长基金 CapitalG，Sequoia、a16z、Menlo Ventures 等老股东继续加注。三个月后的今天，成交价超过 70 亿美元，账面翻了 5 倍多。

[p007]
更有意思的是价格的变化方向。

[p008]
7 月下旬，《华尔街日报》和 Axios 报道双方谈判价在 100 亿美元上下，三周之后落定在 70 亿出头，比传闻低了约三成。

[p009]
分析人士把砍价归因于一个事实：整个夏天，模型价格一路在跌，买家手里的议价筹码越来越硬。

[p010]
自称「AI 界的 Stripe」，这次真被 Stripe 收编了

[p011]
OpenRouter 2023 年初开始运营，创始人兼 CEO Alex Atallah 是斯坦福和 Palantir 出身，2017 年与 Devin Finzer 联合创办了 NFT 交易平台 OpenSea 并担任 CTO，是硅谷最熟悉「市场聚合」这门生意的人之一。

[p012]
OpenRouter 做的事，本质上就是把碎片化的模型市场聚合成一个统一入口：开发者只要接入一个兼容 OpenAI 接口的 API key，就能调用几百个模型，路由、故障转移、用量统计、计费全由它处理，切换模型不用重写代码。

[p013]
按它自己的说法，目前全球用户超过 1000 万，可调用 500 多个模型、来自 80 多家提供商，每月处理 200 万亿以上的 tokens（以上为自报数字）。

[p014]
它的收费模式简单粗暴：按量付费场景收 5.5% 平台费，模型推理价格原样透传。Atallah 曾多次自称是「AI 领域的 Stripe」：给开发者一个单一接入点，避免被任何一家模型厂商锁定。

[p015]
如今这个类比有了最直白的结局，说自己是 Stripe 的公司，被 Stripe 买走了。

[p016]
Stripe 早就在给 OpenRouter 记账，从服务商变成了老板

[p017]
这笔交易的铺垫比外界看到的深。Stripe 本来就是 OpenRouter 的支付服务商，在 Stripe 官方客户案例里，OpenRouter 用它开票、算税、接本地支付方式、做反欺诈，甚至把模型成本的变动和用量计费做了联动。

[p018]
也就是说，Stripe 一直看得见 OpenRouter 账本上的每一笔收入。从供应商到收购方，它比任何外部买家都清楚这个中间层的现金流长什么样。

[p019]
更关键的是战略位置。今年 4 月的 Stripe 开发者大会上，公司密集发布了一组 AI 支付产品：按 token 计费的流式支付、给智能体用的钱包、机器与机器之间的小额支付轨道，官方原话是「token 正变得与货币可互换」。买下 OpenRouter 之后，Stripe 同时握住了两块核心资产：OpenRouter 决定一次推理请求发给哪个模型、记下它值多少钱，Stripe 负责收钱、结算、记到账上。计量和收款，第一次装进了同一家公司。

[p020]
中立性是全部卖点，现在归了收手续费的

[p021]
对开发者来说，最微妙的变化在这里。OpenRouter 立身之本是一句话：中立。它不卖自己的模型，只做调度和计费，所以开发者愿意把流量交到它手里，赌它不会偏袒任何一家模型厂商。

[p022]
现在这个「中立」的担保人变成了收手续费的支付公司。有开发者直接点破：「OpenRouter 本来就用 Stripe 收款，这笔收购能帮 Stripe 降成本、增收入。」

[p023]
也有人引用一个更扎眼的数据：「Forbes AI 50 里所有实现商业化的公司，都在用 Stripe 收款，这有点令人不安。」中间商的业务天然会合并，一个 API key 面对碎片化生态、收一笔便利费，这个生意模型的收编方，这次是收过路费最大的一家。

[p024]
另一层风险是技术上的。路由层是典型单点：它一旦故障，背后所有模型提供商一起遭殃。今年 2 月 OpenRouter 两次宕机，其中一次 80% 到 90% 的 API 请求失败。开发者把「选谁」的自由交给一个中立调度者，和把「选谁」的自由交给一家支付巨头，是两种完全不同的信任。

[p025]
美元和 token 的清算所，Stripe 想一起端走

[p026]
把镜头拉远，OpenRouter 可能只是 Stripe 棋盘上的一块。 就在同一周，8 月 14 日《华尔街日报》报道，Stripe 与私募巨头 Advent 正在洽购 PayPal，7 月提出的每股 60.5 美元报价对应估值约 530 亿美元，被 PayPal 拒绝后谈判仍在继续，若成交 Stripe 年处理的交易额将站上 3.7 万亿美元的量级。

[p027]
一边是美元支付的存量巨头，一边是 token 支付的增量入口。Stripe 想要的不是一个路由层，而是「钱在流动时经过我」这件事本身，不管是法币还是 token，不管收款的是人类还是智能体。OpenRouter 曾宣称要让模型市场保持充分竞争，如今这个市场的计量表和收费闸门，装进了同一家公司手里。对每天在它上面调模型的开发者来说，接口没变，变的是这条路上每一笔过路费的归属。
