# OpenAI 把 ChatGPT 塞进投行：数据内置、直连彭博，金融民工要失业？

[p003]
编译：深潮 TechFlow

[p004]
深潮导读：OpenAI 正式推出面向金融服务业的企业级 ChatGPT，内置 Daloopa、PitchBook、LSEG 等金融数据源，并与摩根士丹利、Evercore 深度合作。对投行和券商从业者而言，这不仅是效率工具，更是研究方法和工作流的一次重新定义。

[p005]
我们正式推出 ChatGPT for Financial Services，这是一款定制化的 ChatGPT Work 体验产品，将内置金融数据与 GPT‑6 Astra 的推理能力结合，帮助团队开展研究、构建财务模型，并制作定制化客户材料。

[p006]
这款产品由我们与摩根士丹利和 Evercore 的设计合作打磨而成。这段合作帮助我们精准定位 OpenAI 能够为金融机构解决的最大挑战，并指导我们打造出能够帮助每一位银行家日常工作的解决方案。

[p007]
来自 Daloopa、PitchBook、LSEG News 和 Crunchbase 等提供商的内置优质数据，消除了 MCP 连接器和数据访问带来的麻烦。这些数据由 OpenAI 索引和托管，以实现更高准确率和颗粒级引用等新功能，让银行家能够追溯每一个数字和结论的原始来源，并在分析推进过程中随时核查证据。

[p008]
该产品还原生提供最前沿的智能能力，包括 GPT‑6 Astra，并将在未来新模型发布时持续开箱即用地提供更新。企业还可以通过 ChatGPT 的企业级安全和治理控制，集中管理访问权限和数据连接。

[p009]
由金融专业经验塑造的前沿研究

[p010]
我们与摩根士丹利和 Evercore 的早期合作，帮助我们确定了起点：投资银行和股票研究。可靠的数据访问和高质量的成果生成，被证明是他们团队最大的痛点。我们与合作伙伴的工作将影响后续训练、产品改进，以及我们向其他金融服务品类的拓展。

[p012]
「前沿研究的价值，在于它真正帮助我们的员工完成对客户至关重要的工作。我们正与 OpenAI 并肩合作，将这种智能带入我们研究公司、开展分析、准备建议的方式中。我们可以一起验证想法，并参与塑造这项技术的发展方向。对我们而言，这意味着产品会越来越贴合我们的人、我们的方法，以及对我们客户真正重要的工作。」（摩根士丹利）

[p013]
「在 Evercore，我们聚焦于对客户最重要的问题，并有机会运用前沿智能来帮助解答它们。我们正与 OpenAI 紧密合作，塑造其技术如何深化我们建议背后的洞察，同时延续客户对 Evercore 所期待的判断力与严苛标准。」（Evercore）

[p014]
数据是所有金融分析的基础

[p015]
ChatGPT for Financial Services 汇聚了团队所需的金融数据，并具备所期望的细节深度。我们纳入了优质金融数据，精简了既有供应商的连接，并改进了 MCP 性能。

[p016]
图：ChatGPT for Financial Services 将内置数据、已连接的数据源与金融分析工作流整合在一起。

[p018]
ChatGPT for Financial Services 包含来自 Daloopa、PitchBook、LSEG News 和 Crunchbase 等提供商的数据集，覆盖业绩电话会记录、财务报表、公司基本面、非上市公司等。

[p019]
团队可以立即开始使用这些数据集，无需另行协商合同或配置连接器。我们在 OpenAI 基础设施上对这些数据进行索引和托管，从而提升检索质量、降低延迟，并改善其在产品体验中的呈现方式。

[p020]
对于正在做 P&L 归一化分析的银行家来说，这意味着能够核查调整后 EBITDA 背后的勾稽关系与附注，理解哪些成本被排除在外，并决定如何在估值中使用它。

[p021]
我们的合作伙伴是这项工作的核心。随着我们拓展数据覆盖，我们将持续加深模型对这些数据集的理解。我们会对模型进行后续训练，使其能像最优秀的分析师那样去寻找、解读和运用这些数据。

[p022]
图：将数字与论断追溯到具体的表格和段落，并高亮显示支持性信息供核查。

[p024]
「金融研究的价值取决于其输入的质量，但可靠的私募市场数据往往难以从公开来源中找到并验证。如今，Crunchbase 结构化的非上市公司数据，覆盖公司、融资、投资人和收购，并持续更新与验证，将触手可及地呈现在使用 ChatGPT 的金融团队面前。借助 Crunchbase 数据，金融团队能够更快地从问题走向有意义的洞察。」（Crunchbase CEO Jager McConnell）

[p025]
「我们很荣幸被选为 OpenAI for Financial Services 的原生数据合作伙伴之一。这延续了我们作为金融服务领域 AI 与智能体工作流数据基础设施的战略。与 OpenAI 的合作是一个巨大的机会，能够扩大对一流基本面数据的获取，并将准确的财务数据直接交到投资者手中，就在他们已经工作的地方。」（Daloopa CEO Thomas Li）

[p026]
「私募市场向来难以看清，而要获得清晰图景，意味着要把分散在市场中各处的数据拼凑起来。PitchBook 近二十年来一直用投资者可以依赖的数据与洞察填补这一鸿沟。与 OpenAI 的合作，标志着这个行业的方向：答案将建立在可信数据之上，而不仅仅是速度。」（PitchBook 技术与工程执行副总裁 Tom Van Buskirk）

[p028]
我们知道，许多客户已经拥有现有的数据订阅。因此，我们正在与 S&P Capital IQ、LSEG、MSCI、Dow Jones Factiva 和 Moody's 合作，推进共享登录和权限集成。供应商将能够通过用户的 ChatGPT 登录来识别他们，从而自动开放他们已经有权访问的数据。

[p030]
「可信数据是每个 AI 工作流的基础。将 S&P Global AI Data Portal 引入 ChatGPT，让金融专业人士能在他们已有的工作环境中，直接获取我们经过验证的全面情报，从财务数据、电话会记录到市场和能源数据。我们很自豪能与 OpenAI 合作，通过 ChatGPT for Financial Services 提供自适应和确定性检索。」（S&P Global 首席客户官兼市场情报联合负责人 Sally Moore）

[p031]
「我们与 OpenAI 的合作推进了我们的 LSEG Everywhere AI 战略。通过 MCP 连接和精选的 Reuters 新闻内容，我们致力于让客户无论想在何处工作，都能获取 LSEG 可信、经授权的内容和分析。」（LSEG 企业级 AI 集团负责人 Emily Prince）

[p032]
与金融供应商更可靠的连接

[p033]
有效使用 MCP 连接器对接数据供应商可能很有挑战性。我们专注于优化金融服务中一些最常用的 MCP，使其能在产品中即时可用，这样团队就能减少排查请求的时间，把更多时间花在分析上。

[p034]
我们更广泛的连接器生态包含超过 50 个连接器，其中包括 Datasite、Box、Preqin、FactSet 和 Intapp。

[p035]
让 GPT‑6 Astra 投入金融分析工作

[p036]
GPT‑6 Astra 在金融服务工作所需的三个核心能力上达到了领先水平：信息检索、金融推理和成果生成。

[p037]
它能够浏览并理解财务文件中的数字、表格和附注。它能够接收输入、运行财务分析并得出结论。它还能把所有这些工作准确地整合成文档、电子表格和幻灯片。

[p038]
我们在产品中构建了基础能力，让它能够跨多个来源进行研究，追踪不同时期的数字，并解读公开数据中的注释。分析完成后，团队可以构建交互式图表和可视化。

[p039]
图：在交互式图表中比较公司性能，底层数据与来源可供审查。

[p040]
把分析转化为团队可用的成果

[p041]
在 ChatGPT for Financial Services 中，管理员可以通过专门的管理页面发布 Excel、Word 和 PowerPoint 模板。配置好公司模板和风格指南后，团队就能以公司要求的格式和风格，把分析转化为估值模型、研究笔记和推介材料。

[p042]
图：将公司模板发布给使用它们的团队。

[p043]
在可信的安全与治理框架下工作

[p044]
保护重大非公开信息和客户机密对金融机构至关重要。ChatGPT for Financial Services 建立在 ChatGPT Enterprise 的 SAML SSO、SCIM 配置和基于角色的访问控制之上。

[p045]
你公司的业务数据默认不会用于训练我们的模型。数据在静态存储和传输过程中都会加密，管理员可以配置工作区留存策略。合规团队可以通过 OpenAI Compliance Platform 将支持的工作区日志导出到他们现有的审计和调查流程中。

[p046]
公司可以按角色管理对技能和应用的访问权限，并启用或禁用受支持应用的读写操作。还可以创建多个工作区以实施信息隔离。
