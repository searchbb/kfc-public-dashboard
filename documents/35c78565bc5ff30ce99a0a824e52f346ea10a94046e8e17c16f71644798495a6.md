# Tokens超级工厂，谷歌TPU比英伟达GPU思考的清楚，技术上更成熟

[p003]
[p002]
> 来源：[原文链接](https://mp.weixin.qq.com/s/y4xmRWJRPoX9TKOWldF5_A)

[p004]
[p003]
过去十年，整个半导体行业的核心逻辑非常清晰：谁拥有最先进制程，谁就拥有最高性能芯片。因此，7nm、5nm、3nm 以及 EUV 光刻机成为了全球半导体的绝对竞争焦点。[谷歌股价赶上英伟达之时，算力从业者将大量失业，很多算力公司已经赚不到钱，应该止损](https://mp.weixin.qq.com/s?__biz=MzYyMTI5MjIyMA==&mid=2247488011&idx=1&sn=e2775bb0ceb7f2e52957696efd2775a0&scene=21#wechat_redirect)但在大模型爆发的今天，一个更深层、更具颠覆性的产业变化正在发生：“先进制程”的重要性，正在被“先进封装”重新定义。

[p005]
[p004]
真正决定 AI 系统性能的，越来越不是单颗 GPU 的制程节点，而是谁能把更多的 Chiplet、HBM、高速互联、电源配送（PDN）和散热网络，整合成一个超级计算系统。

[p006]
[p005]
![Image](assets/Tokens%E8%B6%85%E7%BA%A7%E5%B7%A5%E5%8E%82%EF%BC%8C%E8%B0%B7%E6%AD%8CTPU%E6%AF%94%E8%8B%B1%E4%BC%9F%E8%BE%BEGPU%E6%80%9D%E8%80%83%E7%9A%84%E6%B8%85%E6%A5%9A%EF%BC%8C%E6%8A%80%E6%9C%AF%E4%B8%8A%E6%9B%B4%E6%88%90%E7%86%9F-a35b2ed1be/01-image.png)

[p007]
[p006]
在这一轮范式转移中，谷歌 TPU 的“超级封装路线”，正在系统效能上悄悄超越英伟达 GPU 的传统模式。当许多人还在津津乐道 CUDA、Hopper、Blackwell 或 NVLink 时，AI 算力战争实际上已经跨越了单点架构，进入了下一阶段——“系统级封装战争”。

[p008]
[p007]
# 算力已经不仅仅是“ AI芯片”

[p009]
[p008]
这其实是目前整个行业最大的误判。

[p010]
[p009]
很多人依旧在用传统 CPU 时代的思维去理解如今的 AI GPU。

[p011]
[p010]
但审视今天的顶级 AI 加速器，无论是 H100、B300、MI450，还是 TPU 和国产 Ascend 系列，它们的本质早就不再是一颗单一的芯片（Chip）。它们是一个“超级电子系统”。

[p012]
[p011]
打开封装外壳，里面密密麻麻地集成了：

[p013]
[p013]
* 海量的 HBM 堆叠

[p014]
[p014]
* 负责 I/O 和互联的专属 Die

[p015]
[p015]
* 庞大且昂贵的硅中介层（Interposer）

[p016]
[p016]
* 复杂的电源网络结构

[p017]
[p017]
* 挑战物理极限的热管理结构

[p018]
[p018]
在今天，真正决定 AI 芯片交付性能的，不再只是晶体管数量，而是系统级封装（System-in-Package）的统筹能力。

[p019]
[p019]
# 为什么先进封装突然变成核心基础设施

[p020]
[p020]
核心动因是：单 Die 的物理扩容已经接近摩尔定律的极限。

[p021]
[p021]
过去提升算力的方法简单粗暴——缩小制程、塞入更多晶体管、拉高频率。但在大模型时代，AI 芯片呈现出五个不可逆的趋势：Die 越来越大、HBM 需求翻倍增长、Chiplet 模块激增、单点功耗飙升（如 B300 功耗直逼 1200W）、热密度随之达到极其恐怖的地步。

[p022]
[p022]
结果就是，传统的 BGA 封装彻底“爆缸”了。以前单颗 Die 外挂 DDR，几十瓦功耗就能搞定；现在处理千瓦级的热量和上万根信号引脚，这是一项超级计算机级别的工程。![Image](assets/Tokens%E8%B6%85%E7%BA%A7%E5%B7%A5%E5%8E%82%EF%BC%8C%E8%B0%B7%E6%AD%8CTPU%E6%AF%94%E8%8B%B1%E4%BC%9F%E8%BE%BEGPU%E6%80%9D%E8%80%83%E7%9A%84%E6%B8%85%E6%A5%9A%EF%BC%8C%E6%8A%80%E6%9C%AF%E4%B8%8A%E6%9B%B4%E6%88%90%E7%86%9F-a35b2ed1be/02-image.png)

[p023]
[p023]
通过硅中介层（Interposer）和 TSV（硅通孔）技术，计算 Die 与 HBM 实现了超高密度的互连，这正是现代 AI 芯片的物理基础。

[p024]
[p024]
# 算力不再由 GPU 决定，而是由“HBM + 封装”决定

[p025]
[p025]
这是整个行业最关键的认知转向。在实际的 AI 训练和推理场景中，绝大多数时间的瓶颈并不是 GPU 内部的张量核心算力不够，而是显存带宽不够。因此，AI 芯片的真正核心技术底座已经变成了：HBM、TSV、CoWoS、Interposer 以及 2.5D/3D 封装技术。![Image](assets/Tokens%E8%B6%85%E7%BA%A7%E5%B7%A5%E5%8E%82%EF%BC%8C%E8%B0%B7%E6%AD%8CTPU%E6%AF%94%E8%8B%B1%E4%BC%9F%E8%BE%BEGPU%E6%80%9D%E8%80%83%E7%9A%84%E6%B8%85%E6%A5%9A%EF%BC%8C%E6%8A%80%E6%9C%AF%E4%B8%8A%E6%9B%B4%E6%88%90%E7%86%9F-a35b2ed1be/03-image.jpg)GPU 必须与 HBM 实现物理空间上的“超近距离接壤”。如果在传统 PCB 板上拉线，数据的搬运功耗将会爆炸，延迟更是大模型无法承受的。从这个角度看，HBM 的本质不是单纯的内存，而是 AI 系统封装中不可分割的一部分。![Image](assets/Tokens%E8%B6%85%E7%BA%A7%E5%B7%A5%E5%8E%82%EF%BC%8C%E8%B0%B7%E6%AD%8CTPU%E6%AF%94%E8%8B%B1%E4%BC%9F%E8%BE%BEGPU%E6%80%9D%E8%80%83%E7%9A%84%E6%B8%85%E6%A5%9A%EF%BC%8C%E6%8A%80%E6%9C%AF%E4%B8%8A%E6%9B%B4%E6%88%90%E7%86%9F-a35b2ed1be/04-image.jpg)

[p026]
[p026]
# 英伟达的护城河是锁定的台积电的产能

[p027]
[p027]
很多人以为 NVIDIA 独步天下的是软件生态 CUDA。但实际上，在硬件交付层面，它更强大的是其“超级封装生态”。

[p028]
[p028]
设计 H100 或是 B300 的 GPU Die 固然极难，但真正“卡脖子”的是：如何把多个大尺寸 Die 和多颗 HBM 稳定地封装在一起，并在超高功耗下维持超高速互联且不烧毁。这需要 CoWoS 产能、超大尺寸的硅中介层、顶尖的 ABF 载板、无瑕疵的 TSV 穿孔工艺以及极其精密的电源配送网络。放眼全球，真正能把这一套系统长期稳定量产的，唯有台积电。英伟达当前对台积电的绝对依赖，并不全是因为 4nm/3nm 制程，而是它离不开台积电的CoWoS 超级封装能力。

[p029]
[p029]
# 谷歌 TPU 走向“超级封装架构”是胜出关键

[p030]
[p030]
在这一局域内，谷歌比很多芯片公司更早看透了终局：AI 的未来，绝不是单卡性能的角逐，而是超大规模系统的协同。

[p031]
[p031]
谷歌的初衷从来不是“卖几张世界上最快的显卡”，它的核心诉求是“运营全球最大的 AI 超级计算系统”。

[p032]
[p032]
这也使得 TPU 的设计哲学，从根本上就与 NVIDIA 存在分歧。[超越英伟达，谷歌第8代TPU详解，预训练和后训练是两种AI芯片需求，AI 是个系统而不仅是个芯片](https://mp.weixin.qq.com/s?__biz=MzYyMTI5MjIyMA==&mid=2247487943&idx=1&sn=8df9d8f109e9f558a61b710db10e124d&scene=21#wechat_redirect)

[p033]
[p033]
系统视角的差异：交互模型演示了英伟达 Scale-up 极致堆料与谷歌横向 Pod 互联在扩展至数据中心级别时，所面临的功耗和互连瓶颈差异。

[p034]
[p034]
# 英伟达挥之不去的“GPU思维”

[p035]
[p035]
即便到了 Blackwell 世代，其架构已经极其先进，但 NVIDIA 的骨子里依然保留着“单 GPU、NVLink、Scale-Up”的传统思维——也就是试图把一个“超级节点”的能力榨干到极致。

[p036]
[p036]
英伟达犯了大公司病，gpu，cpu，ib 团队割据，相互拉踩，VR200正在努力追赶 TPU OCS

[p037]
[p037]
这条路线的隐患在于，功耗和热密度正变得越来越不可控。B200 的功耗暴涨、HBM 数量的堆砌、CoWoS 面积的逼近极限，最终都会在物理层面上重重撞上封装极限。

[p038]
[p038]
# 谷歌给出的是一台算力超级系统

[p039]
[p039]
TPU 从立项的第一天起，就是彻头彻尾的“数据中心级架构”。谷歌从不把 TPU 视为显卡，而是将其作为“超级节点”的一个组件。

[p040]
[p040]
它的核心思想不是单卡最强，而是系统效率最高。因此，TPU 架构极度强调：

[p041]
[p041]
* Pod 横向集群架构

[p042]
[p046]
# 光互联，超级封装的下一个杀手锏

[p043]
[p047]
未来 AI 算力扩容的最大阻碍不是 FLOPS（计算量），而是数据移动。

[p044]
[p048]
GPU 计算性能越强、HBM 带宽越高，系统的功耗就越惊人。如果不做出改变，整个集群大部分的电能将被浪费在“把数据从 A 点搬运到 B 点”上。而在机架之间，传统铜缆互联已经逼近极限。

[p045]
[p049]
这也是为什么谷歌在CPO（共封装光学）、硅光技术、光交换领域投入巨大的原因。![Image](assets/Tokens%E8%B6%85%E7%BA%A7%E5%B7%A5%E5%8E%82%EF%BC%8C%E8%B0%B7%E6%AD%8CTPU%E6%AF%94%E8%8B%B1%E4%BC%9F%E8%BE%BEGPU%E6%80%9D%E8%80%83%E7%9A%84%E6%B8%85%E6%A5%9A%EF%BC%8C%E6%8A%80%E6%9C%AF%E4%B8%8A%E6%9B%B4%E6%88%90%E7%86%9F-a35b2ed1be/05-image.png)

[p046]
[p050]
通过将光通信模块直接与计算核心共封装，系统通信功耗被大幅降低，让成千上万个 TPU 构成一个逻辑上的“超级芯片”。

[p047]
[p051]
# 谷歌TPU “Chiplet + 光互联”的基因

[p048]
[p052]
当单 Die 无法继续做大，AI 芯片不可避免地走向大规模 Chiplet 化：

[p049]
[p053]
将多计算 Die、多 HBM、多 IO Die 和光互联模块通过 3D 堆叠和 Hybrid Bonding 组合在一起，最终形成“超级封装系统”。

[p050]
[p054]
![Image](assets/Tokens%E8%B6%85%E7%BA%A7%E5%B7%A5%E5%8E%82%EF%BC%8C%E8%B0%B7%E6%AD%8CTPU%E6%AF%94%E8%8B%B1%E4%BC%9F%E8%BE%BEGPU%E6%80%9D%E8%80%83%E7%9A%84%E6%B8%85%E6%A5%9A%EF%BC%8C%E6%8A%80%E6%9C%AF%E4%B8%8A%E6%9B%B4%E6%88%90%E7%86%9F-a35b2ed1be/06-image.jpg)

[p051]
[p055]
TPU 没有图形渲染的历史包袱，也不必承担 CUDA 通用计算的负担，它是专为大规模张量（Tensor）和数据中心集群而设计的。这使得其架构天然更适合这种演进。

[p052]
[p056]
# token 经济，Tokens / Watt 的较量

[p053]
[p057]
tokens 成本是由=算力成本+电力成本+模型效率 3 方面决定的，tokens 经济产业的终极竞争，早已不是峰值算力，而是：

[p054]
[p058]
* Tokens / Watt（每瓦成本）

[p055]
[p059]
* Tokens / Dollar（每美元成本）

[p056]
[p060]
* Tokens / Rack（单机架吞吐）

[p057]
[p061]
* Tokens / DataCenter

[p058]
[p062]
在这个维度下，系统封装能力比单颗 GPU 更为关键。

[p059]
[p063]
谷歌的优势在于它同时统御着 TPU、数据中心、光网络、AI 模型、云平台和软件栈，能够以“整个 AI 工厂”的视角进行优化。

[p060]
[p064]
而英伟达更多还是处于 GPU、CUDA 与 NVLink 的逻辑延伸中。

[p061]
[p065]
# 超节点算力系统，AI时代的终极角斗场

[p062]
[p066]
未来的顶级 AI 芯片，形态上将更像是一块“小型超级计算机主板”。竞争核心已全面转移至：

[p063]
[p067]
* 谁能堆叠更多 HBM

[p064]
[p071]
* 谁能优化系统能效，降低 Token 成本

[p065]
[p072]
因此，先进封装的重要性，已经不低于先进制程，甚至超越了先进制程。

[p066]
[p073]
# 不用担心缺电，国产 AI 正在转向学习谷歌 TPU

[p067]
[p074]
未来真正的 AI 战争，已经不是“谁有 GPU”，而是“谁有 AI 超级系统能力”。

[p068]
[p075]
美国目前出口限制的重点，已经从单一芯片扩大到了 HBM、CoWoS、封装设备、Chiplet EDA、高端基板和光互联。

[p069]
[p076]
因为他们已经意识到，封装决定了系统性能的天花板。

[p070]
[p077]
尽管我们在 EUV 和先进制程上客观存在差距，但先进封装的底层逻辑不同——它更偏向工程协同、产业链整合、制造能力、热管理和系统集成。这恰恰是中国最强的方向之一。因此，未来中国真正的机会，不是简单复制 NVIDIA 的老路，而是凭借庞大的智算中心需求，直接进入“超级封装 + 超节点 + AI 工厂”的新时代。大力押注Chiplet、国产 CoWoS 平替、Hybrid Bonding、CPO 硅光、国产 HBM 以及模块化 AIDC。因为 AI 正在把半导体行业从“晶体管竞争”，变成“系统级工业能力竞争”。

[p071]
[p078]
而真正决定未来的，可能已经不是谁拥有最强 GPU，而是谁能构建全球最强的 AI 超级封装系统。
