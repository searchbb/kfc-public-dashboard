# 【开源】小米开源 MiMo Code：终端 AI 编程 Agent 跑百步不"失忆"，Claude Code 遇到对手了

[p005]
[p004]
最近小米 MiMo 团队在 GitHub 开源了一个挺有意思的东西——MiMo Code，上线没多久就冲到 6.7K Star。它是基于开源项目 OpenCode 二次开发的终端原生 AI 编程 Agent，MIT 协议，内置小米自研 MiMo-V2.5 模型限时免费通道，也支持 DeepSeek、Kimi、GLM 等主流 API。它不是又一个 Copilot 式 Tab 补全工具，它的核心命题是：怎么让 AI 在几十甚至上百步的持续执行中，不丢上下文、不降低决策质量、还能跨会话记住你的项目。![Image](assets/%E3%80%90%E5%BC%80%E6%BA%90%E3%80%91%E5%B0%8F%E7%B1%B3%E5%BC%80%E6%BA%90%20MiMo%20Code%EF%BC%9A%E7%BB%88%E7%AB%AF%20AI%20%E7%BC%96%E7%A8%8B%20Agent%20%E8%B7%91%E7%99%BE%E6%AD%A5%E4%B8%8D%E2%80%9D%E5%A4%B1%E5%BF%86%E2%80%9D%EF%BC%8CClaude%20Code%20%E9%81%87%E5%88%B0%E5%AF%B9%E6%89%8B%E4%BA%86-20dd41aef9/01-image.png)

[p006]
[p007]
做过程序员应该深有体会——用 Claude Code 或 Cursor 改个 bug、写个小函数很爽，但一旦让你去做模块重构、项目迁移、多文件联调这种几十步的长任务，Agent 很容易：上下文窗口满了开始"忘事"前面做的架构决策后面被忽略过早宣布"我做完了"但其实漏了一堆小米 MiMo 团队认为根本原因是：现有 Coding Agent 把"记笔记"交给模型自觉，而模型并不会主动、准确地做这件事。所以他们换了思路——让主 Agent 专心干活，状态持久化和上下文重建完全外包给独立子 Agent。MiMo Code 就是围绕这个理念，以"计算 × 记忆 × 进化"三支柱打造的终端编程 Agent。![Image](assets/%E3%80%90%E5%BC%80%E6%BA%90%E3%80%91%E5%B0%8F%E7%B1%B3%E5%BC%80%E6%BA%90%20MiMo%20Code%EF%BC%9A%E7%BB%88%E7%AB%AF%20AI%20%E7%BC%96%E7%A8%8B%20Agent%20%E8%B7%91%E7%99%BE%E6%AD%A5%E4%B8%8D%E2%80%9D%E5%A4%B1%E5%BF%86%E2%80%9D%EF%BC%8CClaude%20Code%20%E9%81%87%E5%88%B0%E5%AF%B9%E6%89%8B%E4%BA%86-20dd41aef9/02-image.png)

# 核心原理，用人话版解释

[p008]
[p010]
## 1️⃣ Main Agent + Checkpoint-Writer SubAgent（解决"失忆"）

[p009]
[p011]
主 Agent 负责读代码、执行命令、调 Git。独立子 Agent（checkpoint-writer）在上下文用到 20%/45%/70% 时触发，把当前工作状态写成结构化文件存盘（checkpoint.md / MEMORY.md / tasks 日志）。等窗口快满时，系统开新窗口，用磁盘上的持久化记忆重建上下文——主 Agent 感觉对话从没断过。这比简单"摘要压缩"靠谱得多，因为 checkpoint 可回溯、可审查。记忆分四层：

[p010]
[p012]
* 会话检查点（checkpoint.md）→ 当次会话工作状态
  * 项目记忆（MEMORY.md）→ 跨会话的架构决策、编码规范
  * 任务进展（tasks//progress.md）→ 树状任务追踪，T1/T1.1…
  * SQLite FTS5 全文历史 → 兜底原文回放

[p011]
[p013]
## 2️⃣ Goal 停止条件 + Max Mode（解决"决策质量 & 假完成"）

[p012]
[p014]
/goal设自然语言停止条件（例："所有单测通过且 commit 已推送"），Agent 想停时由独立裁判模型验证，不满足打回去继续干。Max Mode（可选）：每步并行生成 5 个候选方案，模型当裁判选最优，显著降低长程累积错误率。

[p013]
[p015]
## 3️⃣ Dream & Distill（解决"跨会话进化"）

[p014]
[p016]
/dream：定期扫描历史会话，合并去重、校验路径、压缩过时条目，提炼成精炼项目记忆——越用越懂你项目。/distill：发现你反复做的手动操作，打包成可复用 Skill / SubAgent / Command。

[p015]
[p017]
## 4️⃣ Compose 编排模式

[p016]
[p018]
按 Tab 切到 Compose 模式，给个想法，它自动走：规划→编码→TDD→调试→验证→Review→合并，交付带测试的工业级代码，而非只扔给你一堆 .py。![Image](assets/%E3%80%90%E5%BC%80%E6%BA%90%E3%80%91%E5%B0%8F%E7%B1%B3%E5%BC%80%E6%BA%90%20MiMo%20Code%EF%BC%9A%E7%BB%88%E7%AB%AF%20AI%20%E7%BC%96%E7%A8%8B%20Agent%20%E8%B7%91%E7%99%BE%E6%AD%A5%E4%B8%8D%E2%80%9D%E5%A4%B1%E5%BF%86%E2%80%9D%EF%BC%8CClaude%20Code%20%E9%81%87%E5%88%B0%E5%AF%B9%E6%89%8B%E4%BA%86-20dd41aef9/03-image.png)

# MiMo Code 的核心优点

[p020]
[p024]
✅长任务不"失忆"：独立子 Agent 自动存状态，200 步以上胜率超 Claude Code（官方 A/B：65% vs 50%）✅完全开源不绑定：MIT 协议，支持任意 OpenAI 兼容 API，不锁模型✅零配置起步：内置 MiMo Auto 限时免费通道，首次启动引导，全中文 TUI✅自我进化：Dream/Distill 让 Agent 随使用积累项目知识和工作流✅多智能体切换：build（开发）/ plan（只读分析）/ compose（编排）一键 Tab 切换✅语音输入：基于 MiMo-ASR，动嘴改指令或下达执行命令（登录用户）
