# 研究表明：在基准测试中，编程代理框架设计的影响超过模型规模

[p002]
A comparative study of ten coding agent harnesses, reposted by Hugging Face co-founder and CEO Clement Delangue, found that harness design produces larger benchmark accuracy swings (up to 29 percentage points) than model size differences, with vendor-tuned harnesses like Codex collapsing from 2nd to 9th place when moved from large to small models.
