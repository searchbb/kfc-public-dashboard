[p001]
# DeepSeek 的「斩杀线」，正在重塑 AI 行业的世界观

[p002]
作者｜Techno 之王

[p004]
8 月 4 日，「[DeepSeek](https://zhida.zhihu.com/search?content_id=280814545&content_type=Article&match_order=1&q=DeepSeek&zhida_source=entity) 斩杀线」竟然冲上微博热搜。[V4 Flash](https://zhida.zhihu.com/search?content_id=280814545&content_type=Article&match_order=1&q=V4+Flash&zhida_source=entity) 正式版凭借极致的性价比，在全球 AI 大模型的「成本-性能」坐标系上划出了一条残酷的行业生死线——比它贵的没它强，比它弱的没它便宜。[开发者社区](https://zhida.zhihu.com/search?content_id=280814545&content_type=Article&match_order=1&q=%E5%BC%80%E5%8F%91%E8%80%85%E7%A4%BE%E5%8C%BA&zhida_source=entity)群情振奋，甚至外溢成了更大人群津津乐道的话题。

[p005]
当看起来 AI 世界的[定价权](https://zhida.zhihu.com/search?content_id=280814545&content_type=Article&match_order=1&q=%E5%AE%9A%E4%BB%B7%E6%9D%83&zhida_source=entity)已经易手，所有人为极致性价比欢呼的时候，两天后，8 月 6 日，DeepSeek 在开放平台后台发布了一条简短的公告：「计划近期整体上调 DeepSeek API 服务的定价，预计涨幅较大，请合理安排您的使用。」

[p006]
刚被行业定义为画出「斩杀线」的那只手，为何转头就签了涨价通知。

[p009]
所有的戏剧性背后都有必然性。要理解这次涨价，我们得先看一组数据。

[p010]
这一波讨论热潮的起点，是 8 月 4 日，全球 AI 模型聚合平台 [OpenRouter](https://zhida.zhihu.com/search?content_id=280814545&content_type=Article&match_order=1&q=OpenRouter&zhida_source=entity) 的最新周度统计显示，DeepSeek V4 Flash 已登顶全球模型调用量榜首。同一天，海外开发者平台 OpenCode 披露了一个更惊人的数字——8 月 1 日当天，V4 Flash 在其平台上单日处理 token 总量达到 8 万亿，其中 5 万亿来自免费额度，3 万亿来自付费调用。

[p011]
做个对比，大模型路由平台 OpenRouter 接入了 400 多款模型，全平台日均处理量大约 6.6 万亿 token。DeepSeek 一款模型在一个入口的单日消耗，就超过了一个容纳 400 多款模型的平台的全部流量。

[p012]
而支撑这个天文数字的定价是什么？V4 Flash 缓存未命中输入 1 元/百万 token，输出 2 元/百万 token。对比一下，月之暗面 [Kimi K3](https://zhida.zhihu.com/search?content_id=280814545&content_type=Article&match_order=1&q=Kimi+K3&zhida_source=entity) 的同类价格是输入 21 元、输出 105 元，贵了一个量级都不止。而 Anthropic 最新旗舰模型的价格就更是高出近百倍。

[p013]
这个性价比高到，已经开始让人觉得是一种「定价异常」了。

[p014]
这样的极端的价格落差，必然带来调用量的继续激增。而规模化这堵墙，DeepSeek 也不可能绕过去。

[p015]
很快，V4 Flash API 在 8 月 4 日曾因「前所未有的访问量」出现容量问题。再怎么优化架构，MoE [稀疏激活](https://zhida.zhihu.com/search?content_id=280814545&content_type=Article&match_order=1&q=%E7%A8%80%E7%96%8F%E6%BF%80%E6%B4%BB&zhida_source=entity)再怎么省算力，当请求量以万亿级别涌入的时候，瓶颈就不再是效率问题，而是物理问题——你需要更多的机器，而机器要花钱。

[p016]
类似的情况，Deepseek 在当年横空出世的 2025 年初也经历过，那时候普通用户也一度体验到了「排队」的体感，只不过相对于那时候，现在对基础设施的要求已经不可同日而语。

[p018]
「斩杀线」未必是 Deepseek 想要的

[p019]
「斩杀线」这个概念在过去一周传遍了中文互联网。Artificial Analysis 在实测上百款模型后画出了一张「成本-性能」散点图，DeepSeek V4 Flash 站在最优位置，所有落在它右下方的模型——性能不如它、价格还比它贵——都进入了所谓的「斩杀区」。

[p020]
Artificial Analysis 制作的 AI 模型「斩杀线」｜图片来源：Artificial Analysis

[p021]
这个叙事听起来很过瘾，但它可能也蕴含着另一面的问题：如果你真的「斩杀」了所有竞争对手，流量全部涌向你，你大概率会被自己的成功逼到涨价。

[p022]
因为模型不是软件，它交付的价值不能被无限低成本拷贝，背后基础设施的需求，会随着服务量的上升而快速上升。特别是当基础设施能力在今天并不是无限供给，其[成本曲线](https://zhida.zhihu.com/search?content_id=280814545&content_type=Article&match_order=1&q=%E6%88%90%E6%9C%AC%E6%9B%B2%E7%BA%BF&zhida_source=entity)不是可以靠规模化优势而下降，而可能会因为规模化而上升的时候。

[p023]
实际上，即便是从竞争的角度看，定价也从来不是「越低越好」。低价吸引海量调用，基础设施投入被迫增加，就会被迫涨价，然后斩杀线会上移。那么就需要有一个合理的定价逻辑，在背后来支撑找到更好的平衡点。

[p024]
前段时间听闻过行业内流传的 Deepseek 自己的定价哲学——API 定价基于「把公司在设备等基础设施上的投入做为成本，定价应该以十个月可以收回成本」为基准，设定合理定价和利润模型。

[p025]
这个传闻的内部逻辑听起来非常合理，也非常符合 Deepseek 的发展目标。

[p026]
首先，今天 AI 已经开始加速进入场景和业务，甚至已经开始成为很多个人用户不可或缺的新工作能力组成部分。因为 AI 带来的巨大效率提升，用户需求几乎没有弹性，或者说，即便是 Deepseek 的价格再翻一半，很可能token 的消耗量区别也不会太大。

[p027]
其次，如果从 Deepseek 自身的发展目标来看，之所以采用一个回收成本的定价逻辑作为定价基准，而不是从竞争逻辑逻辑作为定价基准，显然提示它心中有更大的任务和目标，是高于短期内的[利润最大化](https://zhida.zhihu.com/search?content_id=280814545&content_type=Article&match_order=1&q=%E5%88%A9%E6%B6%A6%E6%9C%80%E5%A4%A7%E5%8C%96&zhida_source=entity)的。

[p028]
模型本身还在变大，智能的提升还在继续。模型公司的主要任务还不是极致变现，而是建立合理的[商业循环](https://zhida.zhihu.com/search?content_id=280814545&content_type=Article&match_order=1&q=%E5%95%86%E4%B8%9A%E5%BE%AA%E7%8E%AF&zhida_source=entity)，并支持有足够的资源进一步提升模型的智能。所以，定价是一个必须服务于更大目标的事情。

[p029]
定价真正要解决的是，让自身的业务收入可以成为提供升力的翅膀和肌肉，而不是长在身上越来越厚的肥油。在服务和研发都对基础设施有巨大要求的时候，这需要合理的平衡。

[p031]
Token 终将成为[大宗商品](https://zhida.zhihu.com/search?content_id=280814545&content_type=Article&match_order=1&q=%E5%A4%A7%E5%AE%97%E5%95%86%E5%93%81&zhida_source=entity)

[p032]
把视野拉开，DeepSeek 涨价不是孤立事件，而是整个中国 AI 行业定价逻辑转向的缩影。

[p033]
[智谱](https://zhida.zhihu.com/search?content_id=280814545&content_type=Article&match_order=1&q=%E6%99%BA%E8%B0%B1&zhida_source=entity)在今年一季度的业绩说明会上披露，API 定价较去年底提升了 83%，主要因为 3 月发布的 GLM-5-Turbo 定价更高。但调用量仍然增长了 400%，呈现出典型的「[量价齐升](https://zhida.zhihu.com/search?content_id=280814545&content_type=Article&match_order=1&q=%E9%87%8F%E4%BB%B7%E9%BD%90%E5%8D%87&zhida_source=entity)」态势。

[p034]
月之暗面的动作更加激进。7 月 16 日发布 Kimi K3 后，输入价较前代涨超 3 倍、输出价涨近 4 倍。上线仅三天，就因为「过去 48 小时请求量大幅超出预估」暂停了 C 端新用户订阅，[算力](https://zhida.zhihu.com/search?content_id=280814545&content_type=Article&match_order=2&q=%E7%AE%97%E5%8A%9B&zhida_source=entity)全部保障已订阅用户。

[p035]
现在可以清晰地看到，过去两年，中国模型公司已经跨越了「证明自己」的阶段，赢得了在大模型牌桌上的位置，那么接下来必须回归这张牌桌上的打法，回归到长期竞争的战略上看问题。

[p036]
简单来说，涨价没有降低中国模型公司的竞争力，而是他们必然会选择、提升长期竞争力的动作。

[p037]
当产业长期竞争逻辑来自于智能的高度，智能的高度又来自于组织的和基础设施的能力与效率。而在今天算力成本持续高企、资源供给有限的情况下，那些最好的模型，token 不会越来越便宜，这应该是所有从业者应该看清的趋势了。

[p038]
往更远处看，这次涨价潮揭示了一个更深层的趋势——AI 模型的 token 正在走向大宗商品化。

[p039]
过去一年，前沿模型的能力差距在快速收敛。V4 Flash 的[智能指数](https://zhida.zhihu.com/search?content_id=280814545&content_type=Article&match_order=1&q=%E6%99%BA%E8%83%BD%E6%8C%87%E6%95%B0&zhida_source=entity)仅比 [GPT-5.6 Luna](https://zhida.zhihu.com/search?content_id=280814545&content_type=Article&match_order=1&q=GPT-5.6+Luna&zhida_source=entity) 低 1 分，在多项 Agent [基准测试](https://zhida.zhihu.com/search?content_id=280814545&content_type=Article&match_order=1&q=%E5%9F%BA%E5%87%86%E6%B5%8B%E8%AF%95&zhida_source=entity)中逼近 [Claude Opus 4.8](https://zhida.zhihu.com/search?content_id=280814545&content_type=Article&match_order=1&q=Claude+Opus+4.8&zhida_source=entity)。当模型能力越来越接近、输出质量越来越趋同的时候，token 就越来越像标准化的工业原料——和石油、钢铁没有本质区别。

[p040]
大宗商品的定价逻辑非常简单：成本加合理利润。

[p041]
DeepSeek 之前的定价异常低，不是因为它找到了永久压低成本的魔法，现在规模到某个临界点，价格就会向均衡带回归。

[p042]
未来的均衡态可能是这样的：通用推理 token 的价格在各家之间差距不大，就像 AWS、[Azure](https://zhida.zhihu.com/search?content_id=280814545&content_type=Article&match_order=1&q=Azure&zhida_source=entity)、GCP 的基础算力定价差不多一样。

[p043]
真正的竞争维度会上移——移到[生态锁定](https://zhida.zhihu.com/search?content_id=280814545&content_type=Article&match_order=1&q=%E7%94%9F%E6%80%81%E9%94%81%E5%AE%9A&zhida_source=entity)。例如微软把 GPT 绑进 Office 全家桶，Google 把 Gemini 塞进搜索和安卓、移到垂直场景的深度适配、移到 agent 能力和[工具链](https://zhida.zhihu.com/search?content_id=280814545&content_type=Article&match_order=1&q=%E5%B7%A5%E5%85%B7%E9%93%BE&zhida_source=entity)的完整度。

[p044]
也就是说，「极致性价比」这过去看起来有效的打法，在头部大模型公司的长期竞争中是不合理的路径。谁的 token 更便宜这件事，并不是唯一重要的因素。

[p045]
但另一方面，这也会加快在场景和业务中更合理的智能模型路由，本地模型等对智能生产力更细致的 Harness，这是产业出现新的[价值层](https://zhida.zhihu.com/search?content_id=280814545&content_type=Article&match_order=1&q=%E4%BB%B7%E5%80%BC%E5%B1%82&zhida_source=entity)可能的机遇。

[p048]
这次涨价还有一群沉默的受影响者——那些把业务建在 DeepSeek 超低价 API 之上的创业公司和独立开发者。

[p049]
一个提供 AI 写作辅助的 SaaS 工具，每月处理数十亿 token，之前的 API 成本可能只有几百美元。如果涨价幅度真如公告所暗示的「较大」，成本可能翻到数千美元。对于还没有足够用户规模和收入支撑的项目来说，这不是成本调整，而是生死问题。

[p050]
这是一个值得所有 AI 创业者记住的世界观：你的成本结构不能押注在某一家供应商的促销价上。就像你不会把公司命运系在某个云厂商的限时折扣上一样，把毛利模型建立在 DeepSeek 的地板价之上，本质上是把[风险转移](https://zhida.zhihu.com/search?content_id=280814545&content_type=Article&match_order=1&q=%E9%A3%8E%E9%99%A9%E8%BD%AC%E7%A7%BB&zhida_source=entity)的能力交给了别人。

[p051]
DeepSeek 涨价并不意味着天塌了。有开发者在社区里说得很直白——「就算涨一倍也仍有竞争力。」涨价后的 DeepSeek 性价比大概率仍会领先。但没有哪条「斩杀线」是永恒的，包括 DeepSeek 自己画的那条。

[p052]
但 Deepseek 这次涨价，确实带来了一个更加清晰的世界观，一个新的 AI 产业世界观正在越来越从喧嚣和震荡中，显现出更清晰的模样。
