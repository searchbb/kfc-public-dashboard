# 即便明确指示，AI 智能体仍难以掌握测试技术

[p002]
A systematic evaluation of 26 testing and verification prompt conditions found that no technique dramatically outperformed default agent behavior, with agents applying named techniques superficially — a pattern corroborated by at least four independent academic studies documenting shallow verification practices across the agent ecosystem.
