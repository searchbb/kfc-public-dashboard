# 谱GLM Coding Plan不用抢了，最多涨价两倍，价格向海外看齐

[p005]
智谱近日更新[GLM](https://tech.163.com/keywords/0/4/0047004c004d/1.html) Coding Plan国内版套餐。**最受欢迎的Pro档连续包月原价从149元调整至538元，Lite从49元涨到118元，Max从469元涨到1078元。**

[p006]
按连续包月原价计算，三档涨幅分别约为141%、261% 和130%。

[p007]
涨价之前，这款产品的问题是买不到。过去，国内版GLM Coding Plan最大的吸引力之一，是价格明显低于海外同类产品。**但低价也带来了另一面：不少用户发现，套餐长期处于抢购状态，开放购买后很快售罄，并不是想买就能买。**

[p008]
此外GLM Coding Plan的计费方式也改成了积分制：**输入多少Token、缓存命中多少、输出多少代码、调用多少工具、什么时候运行，都会影响最终消耗。**

[p010]
按照智谱最新文档，三档套餐同时设置每5小时和每周两道积分上限：Lite为2000积分和1万积分，Pro为1.2万积分和6万积分，Max为2.8万积分和14万积分。5小时额度采用动态恢复机制，每周额度则从下单之日起每7天刷新。

[p011]
**积分并不等同于固定数量的Token。** 以GLM-5.2为例，输入Token、缓存输入Token和输出Token的抵扣系数分别为6.9、1.7和24；联网搜索、网页读取和开源仓库读取等工具调用，也会按文档列出的系数计入积分消耗。工作日14时至18时为高峰期，其余时段调用模型只按基础积分消耗的50% 抵扣。

[p012]
**同一个套餐在不同用户手里，实际可用量可能相差很大。** 缓存命中率高、输出短、避开高峰，积分就用得慢；反过来，长输出、多轮智能体任务、频繁调工具，积分掉得就快。

[p013]
智谱以全部使用GLM-5.2、缓存命中率达到90.9% 为前提估算，Lite每周可用约4300万至8700万Token，Pro约2.63亿至5.26亿，Max约6.13亿至12.26亿。**区间上下限主要取决于是否处于高峰时段，这些数字并不是所有用户都能获得的固定额度。**

[p014]
三档套餐之间的关系也发生了变化。旧版页面将Pro标为Lite用量的5倍、Max为20倍；按当前积分上限计算，Pro变为Lite的6倍，Max则降至14倍。**Pro的相对额度提高了，但价格涨得更快。Max价格翻了一倍多，"20倍Lite"这个原本的卖点却没了。**

[p015]
**用户吵的是：还值不值**

[p016]
价格更新后，开发者社区上一则相关帖直接以"恐怖故事"形容这轮涨价。讨论里，有用户直接拿智谱和海外模型对比：**Pro月费涨到538元，为什么不直接订GPT或Claude？Max进了千元价位，价格优势还剩多少？** 也有人表示，自己原本正考虑购买GLM套餐，新价格公布后决定继续观望。

[p017]
Reddit上使用海外版的GLM用户也注意到，Pro的标称额度由Lite的5倍提高至6倍，Max却由20倍降至14倍。**对Max用户而言，这意味着月费涨至1078元的同时，相对Lite的额度倍数反而下降。** 另一些用户则追问，积分制上线后，每周额度究竟能完成多少次真实的编程任务。

[p018]
还有用户担心，官方给出的Token用量建立在较高缓存命中率之上，而实际使用智能体时，长输出、反复读取上下文和频繁调用工具都可能加快积分消耗。**因此，他们更希望看到不同编程场景下的实测，而不只是理论Token上限。**

[p019]
不过，也有用户认为，GLM仍有人民币支付、国内网络访问和采购便利等优势。**对无法稳定购买海外模型的个人，以及需要考虑采购渠道和数据合规的机构来说，价格并不是唯一标准。**

[p020]
**智谱为什么这时候涨价**

[p021]
智谱没有对7月这次国内调价作出完整说明，但从公开价格和公司此前披露的信息，能看出几个背景。

[p022]
**一个是付费规模已经起来了。** 智谱3月底发布的2025年业绩公告显示，GLM Coding Plan付费开发者超过24.2万。公司在同一份文件里，把模型能力和"核心定价权"绑在一起，还提到2月已经主动上调过Coding Plan价格、取消首购折扣。截至今年3月，智谱称API调用价格较2025年底提高了83%，需求仍然超过供应。**这些数据不能证明7月涨价后的用户还会全部留下，但至少说明智谱具备测试更高价格的条件：付费盘子已经形成，API需求仍紧，此前的涨价也没让用户跑光。**

[p023]
**另一个是算力成本确实在涨。** 智谱2025年销售成本同比增长213.3% 到4.277亿元，公司把主要原因归为业务扩张带来的算力服务费增加。同期研发支出31.804亿元，明显高于7.243亿元的全年营收。这些是公司整体数据，不能直接换算成Coding Plan单项成本，**但也说明大模型订阅和传统软件不一样：每多一个用户，成本会跟着涨。**

[p024]
目前GLM Coding Plan国内外价差已经被抹平。Z.ai海外版三档月付原价为18、80和168美元。按发稿时实时汇率换算（1美元≈6.747元人民币），海外三档月费约合121元、540元和1133元。如果不算税费等差异，国内价格几乎和海外一致。**智谱并没有宣布全球统一定价，但国内版已经从过去明显更便宜的获客价格，走到了和海外接近的水位。国内用户不再享有明显的价格折扣。**

[p025]
积分制和涨价同时上线，还有一层控制成本的意思。月费上涨提高了单个用户贡献的收入；输入、缓存、输出和高峰时段用不同抵扣规则，则让长输出、低缓存和重度智能体任务多消耗积分，减少少数高负载用户集中占用套餐资源。

[p026]
**所以整体看，低价阶段已经帮智谱把用户攒起来了，现在公司一边把国内价格拉向海外价格带，一边用积分制把不同任务的资源成本分开算，从低价获客转向提高变现。**

[p027]
截至7月31日发稿时，智谱国内页面尚未给出针对7月调价的完整老用户迁移说明。海外版7月30日公告中，现有活跃套餐可以在当前周期内维持原价和旧规则。**对新订阅用户而言，新价格及积分规则已经生效。**
