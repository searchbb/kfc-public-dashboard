# 隆重宣布：在 Cloudflare 上正式推出 Claude Managed Agents

[p002]
> 来源：[原文链接](https://mp.weixin.qq.com/s/B1ycdfo07LmWdKxO599jNg)

[p003]
![Image](assets/%E9%9A%86%E9%87%8D%E5%AE%A3%E5%B8%83%EF%BC%9A%E5%9C%A8%20Cloudflare%20%E4%B8%8A%E6%AD%A3%E5%BC%8F%E6%8E%A8%E5%87%BA%20Claude%20Managed%20Agents-47aaea92ed/01-image.png)Cloudflare 已与 Anthropic 达成合作，将 Claude Managed Agents 集成到 Cloudflare Sandboxes。此次[全新集成](https://developers.cloudflare.com/sandbox/tutorials/claude-managed-agents/)赋予了您对智能体沙盒更强的掌控力，保障了通往私有服务连接的安全性，并显著提升了可观测性。在过去的一年中，Cloudflare 开发者平台不断扩充，为更多开发者提供了大规模运行智能体所需的关键工具。其中包括：

[p004]
* [Sandboxes](https://developers.cloudflare.com/sandbox/)，支持大规模、全状态的 Linux 微型虚拟机
  * [Agents SDK](https://developers.cloudflare.com/agents/)，提供简单且高度可定制的智能体开发框架
  * [Browser Run](https://developers.cloudflare.com/browser-run/)，为智能体提供完全可编程且具备可观测性的浏览器环境
  * [Dynamic Workers](https://developers.cloudflare.com/dynamic-workers/)，支持在大规模并发下运行动态、沙盒化的代码执行环境

[p005]
我们的目标是使 Cloudflare 成为构建智能体最简单、最安全且最可编程的云平台。此次与 Claude Managed Agents 的集成，是我们迈向这一目标的又一重要举措。您可以在 Claude 平台上运行智能体的核心循环，同时利用 Cloudflare 的基础设施来执行代码、保障连接安全并运行自定义工具调用。为了让您在几分钟内快速启动，我们创建了一个默认的[默认部署模板](https://github.com/cloudflare/claude-managed-agents)，为您提供以下核心功能：

[p006]
* 增强安全性 \- 通过可自定义的代理运行所有智能体流量。这使您能够安全地注入凭据、防止数据泄露，并更好地观察您的智能体如何与外界互动。
  * 沙盒控制和可观测性 \- 获取详细的沙盒指标与日志，支持通过 SSH 进入正在运行的实例，并支持自定义沙盒镜像。
  * 轻量级沙盒 \- 可以在传统 microVM 或 [轻量级隔离环境](https://blog.cloudflare.com/zh-cn/dynamic-workers/)中编写和执行不受信任的代码。这使您能够实现大规模扩展，以毫秒级启动沙盒，并最大限度地降低基础设施支出。
  * 私有服务连接 \- 将智能体连接至内部私有服务，而无需将其暴露在公共互联网上。
  * 浏览器控制和可观测性 \- 获取每个智能体浏览器会话的审计追踪，包括会话录制和人工干预流程。
  * 电子邮件服务 \- 为您的每个智能体分配专属的电子邮件地址，并赋予其发送邮件的能力。
  * 自定义工具 \- 无需额外构建基础设施即可扩展智能体的工具集，只需编写函数并部署即可使用。

[p007]
在部署该集成后，您即可直接获得上述所有功能，若有更高需求，亦可轻松进行个性化定制。接下来，我们来简要了解一下 Claude Managed Agents，看看如何集成基于 Cloudflare 的环境，然后探索如何在 Cloudflare 上充分利用 Claude。Claude Managed Agents 概述[Claude Managed Agents](https://www.anthropic.com/engineering/managed-agents) 允许开发人员在 Anthropic 平台上轻松定义和运行智能体。在这些托管环境中，Claude 可以读取文件、运行命令、浏览网页和执行代码。该执行框架支持内置的提示词缓存、上下文压缩以及多种面向智能体的性能优化方案。在此之前，使用 Claude 托管智能体意味着必须在 Anthropic 提供的基础设施上运行整个技术栈。虽然这对部分开发者而言非常便捷，但出于安全、合规或性能考量，其他开发者可能需要对基础设施的选择拥有更高的自主权。而 Claude 智能体的“自托管环境”（Self-managed environments）恰好满足了这一需求。Anthropic 将这种架构描述为“大脑与双手的解耦”。智能体的核心逻辑循环（Agent Loop）在 Anthropic 平台运行（即“大脑”），而执行代码和任务的基础设施（即“双手”）则可以在任何地方运行，包括 Cloudflare。Cloudflare 运行环境我们全新的集成方案为您提供了一个基于 Cloudflare 的运行环境，让您的智能体能够在几分钟内完成代码的执行与部署。请按照[入门指南](https://github.com/cloudflare/claude-managed-agents#onboarding-guide)开始配置。随后您可以 fork 我们的代码仓库并根据实际需求进行自定义调整。配置完成后，当 Claude 智能体开启会话时，它会向您新建的 Cloudflare 控制平面发送指令。该基于 [Workers](https://developers.cloudflare.com/workers/) 的控制平面会为每个智能体分配一个独立的沙盒环境，用于执行代码、开发应用、运行 CLI 工具等操作。此外，系统会自动在会话休眠期间维持状态的持久化。![Sandboxes write files and execute code in response to the Claude-based Agent loop](assets/%E9%9A%86%E9%87%8D%E5%AE%A3%E5%B8%83%EF%BC%9A%E5%9C%A8%20Cloudflare%20%E4%B8%8A%E6%AD%A3%E5%BC%8F%E6%8E%A8%E5%87%BA%20Claude%20Managed%20Agents-47aaea92ed/02-image.png)沙盒会在响应基于 Claude 的智能体循环时写入文件和执行代码您可以根据需要配置沙盒实例的大小，或自定义基于虚拟机（VM）的沙盒内运行的容器镜像。您可以通过 Cloudflare 控制台实时监测每个沙盒的运行状态，查询沙盒日志，或将其同步至 Datadog、Splunk 等第三方监控平台。此外，该控制平面自带内置的用户界面，方便您轻松追踪沙盒状态，或通过 SSH 直接远程登录到特定的机器进行操作。![Image](assets/%E9%9A%86%E9%87%8D%E5%AE%A3%E5%B8%83%EF%BC%9A%E5%9C%A8%20Cloudflare%20%E4%B8%8A%E6%AD%A3%E5%BC%8F%E6%8E%A8%E5%87%BA%20Claude%20Managed%20Agents-47aaea92ed/03-image.png)通过交互式 Shell 访问智能体沙盒实现互联网规模的智能体部署如果您的智能体后台在几毫秒内启动，而且运行智能体时无需为完整虚拟机的资源付费，这会怎么样？随着我们大规模采用智能体技术，行业亟需一种轻量级的沙盒基础原语，而这正是我们正在构建的。随着模型能力的不断进化，我们预计会有越来越多的工作流由智能体来托管。您的每一位客户都应能同时运行多个智能体，每一位员工也应能同时开启数十个智能体。如果我们始终为每个智能体分配一个完整的微型虚拟机（microVM），那么在实现这一规模的过程中，我们将不可避免地造成大量资源的浪费，并付出高昂的财务成本。正因如此，我们为您提供了更快速、更具成本效益的 Claude 智能体沙盒。此沙盒基于 [AgentsSDK](https://developers.cloudflare.com/agents/)构建。您可以在 [Dynamic Workers](https://developers.cloudflare.com/dynamic-workers/) 中使用 [Codemode](https://developers.cloudflare.com/agents/api-reference/codemode/) 执行任意代码，并且您仍然能够[获取文件系统](https://developers.cloudflare.com/sandbox/bridge/http-api/#workspace-persistence)，您的智能体将在 [V8 isolate](https://developers.cloudflare.com/workers/reference/how-workers-works/#isolates) 中运行，而非传统的微型虚拟机（microVM）。当然，如果您需要智能体来充当开发人员，进行全栈应用构建或运行基于 Linux 的工具，您依然可以选择基于微型虚拟机的沙盒。为此，我们提供了[ Cloudflare Containers](https://developers.cloudflare.com/containers/)，Claude Managed Agents 同样可以直接调用。但如果您追求更快、更省钱且更具扩展性的替代方案，完全可以轻松改用 Isolate 来替代微型虚拟机。只需在设置智能体时，将后端类型（Backend type）选择为“isolate”即可。![Image](assets/%E9%9A%86%E9%87%8D%E5%AE%A3%E5%B8%83%EF%BC%9A%E5%9C%A8%20Cloudflare%20%E4%B8%8A%E6%AD%A3%E5%BC%8F%E6%8E%A8%E5%87%BA%20Claude%20Managed%20Agents-47aaea92ed/04-image.png)设置“隔离”后端即可为您提供一个基于 V8 的轻量级沙盒，以替代传统的 microVM如果您需要处理数万甚至更多并发智能体的激增需求，使用 Isolate（隔离环境）运行将使您实现传统基于虚拟机的方案所无法企及的扩展能力。保护您的智能体工作负载当智能体能够连接到您组织内部的数据上下文时，其能力将得到质的飞跃。然而，这也通常意味着智能体需要访问企业内部的私有服务与数据。![Image](assets/%E9%9A%86%E9%87%8D%E5%AE%A3%E5%B8%83%EF%BC%9A%E5%9C%A8%20Cloudflare%20%E4%B8%8A%E6%AD%A3%E5%BC%8F%E6%8E%A8%E5%87%BA%20Claude%20Managed%20Agents-47aaea92ed/05-image.png)正如[我们之前所述](https://blog.cloudflare.com/sandbox-auth/)，Cloudflare 上的沙盒工作负载可以使用出站代理（Outbound Proxy），在沙盒与外部服务之间实现完全动态、可定制且符合零信任（Zero-trust）标准的身份验证。通过这种方式，您可以将敏感密钥（Secrets）注入到沙盒之外的请求中，从而确保智能体本身不会直接接触到这些密钥，进而有效防御数据外泄攻击。此外，有些内部服务本就不应暴露在公共互联网上。我们最近推出了 [Cloudflare Mesh](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-mesh/) 和 [Cloudflare Workers VPC](https://developers.cloudflare.com/workers-vpc/)，旨在更好地连接这些私有服务 - 无论这些私有服务是在 AWS 等云提供商上运行，还是在本地运行，均可实现更好的连接。这使您能够使用后量子加密网络连接内部服务，而无需 VPN 或堡垒主机。Claude Managed Agents 可以通过头部注入或私有 VPC/Mesh 隧道轻松连接到私有服务。这是通过可定制的出站代理完成的。您可以定义出口策略，仅向您选择的智能体沙盒公开您选择的服务。您可以将特定终结点加入允许列表，执行加密凭据的 Zero Trust 注入，通过 Cloudflare Mesh 访问私有服务，甚至编写自定义代理中间件。![Image](assets/%E9%9A%86%E9%87%8D%E5%AE%A3%E5%B8%83%EF%BC%9A%E5%9C%A8%20Cloudflare%20%E4%B8%8A%E6%AD%A3%E5%BC%8F%E6%8E%A8%E5%87%BA%20Claude%20Managed%20Agents-47aaea92ed/06-image.png)该集成使用 Outbound Workers 来根据您的需求处理外发流量您可以根据租户（Tenant）、智能体（Agent）或任何有用的元数据（Metadata）来应用策略。这使您能够完全掌控智能体连接外部服务的方式。充分利用 Cloudflare 开发人员平台智能体所需的不仅仅是一个代码执行环境。Cloudflare 开发者平台提供了您所需的一系列默认工具，让您的智能体能够处理更复杂的任务，发挥更大潜力。![Image](assets/%E9%9A%86%E9%87%8D%E5%AE%A3%E5%B8%83%EF%BC%9A%E5%9C%A8%20Cloudflare%20%E4%B8%8A%E6%AD%A3%E5%BC%8F%E6%8E%A8%E5%87%BA%20Claude%20Managed%20Agents-47aaea92ed/07-image.png)Sandboxs 可以在 Cloudflare 上进行工具调用，并安全地访问外部服务。以下是在 Cloudflare 上部署智能体时，您会发现最实用的一些工具：通过 Claude 使用 Browser Run智能体需要的最常用工具之一是浏览器。虽然 curl 功能很强大，但当您希望智能体像人类一样工作时，这通常意味着需要像人类那样与网络互动：渲染 JS 密集型应用程序、拍摄 QA 验证截图、填写表单等。[Browser Run](https://blog.cloudflare.com/browser-run-for-ai-agents/)正是 Cloudflare 为智能体提供的浏览器专用工具。

Browser Run 会话录屏功能让您可以查看智能体是如何使用浏览器的。这是众多内置工具中的其中之一。Claude Managed Agents 集成提供了多种与浏览器相关的工具，可以立即启用。其中包括 browser_search、browser_execute、screenshot、browse、fetch_to_markdown，以及特定于 Cloudflare 的 web_fetch 实现。通过web_fetch ，使您的智能体能够控制在 Cloudflare 基础设施上运行的浏览器。这不仅让您的智能体能够做更多事情，而且还使您能轻松审查智能体浏览器在网络上执行的每个操作，对浏览器会话应用允许列表和拒绝列表，并保存浏览器会话的录制文件以便进行后续的调试和复盘。智能体收件箱该集成还内置了对电子邮件的支持，具备 send_email、email_read 和 email_list 工具。您还可以通过电子邮件触发开启新的会话，或者配置智能体，使其能够使用在 [Cloudflare Email Service](https://blog.cloudflare.com/email-for-agents/) 中配置的任何域名和地址来发送邮件。这使得智能体在必要时能够代表您采取行动、针对转发邮件中的上下文进行回复，并以自动化方式通过邮件与他人进行交互。自定义工具及更多扩展其他内置工具包括 call_service（它使用 Cloudflare Mesh 或 Workers VPC 连接到私有服务）和 image_generate（它使用 [Workers AI](https://www.cloudflare-cn.com/developer-platform/products/workers-ai/) 在 Cloudflare 上生成图像）。这些功能与 Claude 提供的文本推理能力能够完美配合。此外，我们建议将存储库分叉，以便轻松添加自定义工具。例如，您可以添加一个自定义工具，在[Cloudflare 的 R2 对象存储](https://www.cloudflare-cn.com/developer-platform/r2/)上托管公共文件。只需在 Wrangler 配置中添加相关绑定，编写 [zod](https://zod.dev/) 定义，并在 custom-tools.js 中编写简短函数：![Image](assets/%E9%9A%86%E9%87%8D%E5%AE%A3%E5%B8%83%EF%BC%9A%E5%9C%A8%20Cloudflare%20%E4%B8%8A%E6%AD%A3%E5%BC%8F%E6%8E%A8%E5%87%BA%20Claude%20Managed%20Agents-47aaea92ed/08-image.png)Cloudflare 开发人员平台为扩展您的智能体提供了各种可能性：为每个智能体会话提供一个支持 git 的存储库，使用 [Artifacts](https://blog.cloudflare.com/artifacts-git-for-agents-beta/)，通过 [Workers AI](https://workers.cloudflare.com/products/workers-ai/) 运行边缘推理，利用 [Dynamic Workers](https://developers.cloudflare.com/dynamic-workers/)实时托管即时生成的应用程序，等等。您无需为基础设施或扩展性问题操心——只需编写几行代码，点击部署即可。Claude + Cloudflare我们非常高兴能与 Anthropic 携手合作，将 Cloudflare 的灵活性、扩展性和安全性带给更多的用户。无论您是想使用隔离技术运行数千万个智能体，还是通过 Workers VPC 安全连接私有人服务，或是想编写能够充分利用 Cloudflare 全平台能力的自定义工具，我们的全新集成方案都能让这一切变得轻而易举。请参见 [Managed Agents 入门指南](https://developers.cloudflare.com/sandbox/claude-managed-agents/)，只需几分钟，即可完成 Claude Managed Agents 与 Cloudflare 的环境部署。![Image](assets/%E9%9A%86%E9%87%8D%E5%AE%A3%E5%B8%83%EF%BC%9A%E5%9C%A8%20Cloudflare%20%E4%B8%8A%E6%AD%A3%E5%BC%8F%E6%8E%A8%E5%87%BA%20Claude%20Managed%20Agents-47aaea92ed/09-image.png)
