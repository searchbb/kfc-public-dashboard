# 更全面的 Token 套餐来了：Agent Plan

[p002]
> 来源：[原文链接](https://mp.weixin.qq.com/s/WBtL2LXgYSJg4vnPJlXpvQ)

[p003]
作为一名 Token 消耗大户，各模型厂商和云厂商的套餐我基本都有入手：智谱、MiniMax、小米 Mimo，以及最早推出 Coding Plan 的火山引擎，这些都是我目前在订的。

[p004]
以前 Coding Plan 基本能够覆盖日常工作，但是随着越来越多场景依赖 AI 辅助，传统 Coding Plan 的能力不足以覆盖所有场景了，尤其是对图片、视频等多模态的支持都有所缺失。但是，最近在用火山引擎 Coding Plan 的时候，注意到多了一个 **Agent Plan** ，这简直就是现阶段 AI 深度用户最完美的全能套餐！

[p005]
![Image](assets/%E6%9B%B4%E5%85%A8%E9%9D%A2%E7%9A%84%20Token%20%E5%A5%97%E9%A4%90%E6%9D%A5%E4%BA%86%EF%BC%9AAgent%20Plan-81851f4573/01-image.png)

[p006]
## Coding Plan vs Agent Plan

[p007]
看到有这么全面的套餐，二话不说，第一时间拿下，免得后面还得用抢的！

[p008]
![Image](assets/%E6%9B%B4%E5%85%A8%E9%9D%A2%E7%9A%84%20Token%20%E5%A5%97%E9%A4%90%E6%9D%A5%E4%BA%86%EF%BC%9AAgent%20Plan-81851f4573/02-image.png)

[p009]
顺手对比整理了一下 Coding Plan 和 Agent Plan 的主要区别如下表：

[p010]
![Image](assets/%E6%9B%B4%E5%85%A8%E9%9D%A2%E7%9A%84%20Token%20%E5%A5%97%E9%A4%90%E6%9D%A5%E4%BA%86%EF%BC%9AAgent%20Plan-81851f4573/03-image.png)Coding Plan 与 Agent Plan 对比

[p011]
可以看到 Agent Plan 完整覆盖了 Coding Plan 的编程能力，并在此之上增加了多模态和 Harness 工具链。其中，对于多模态的支持，主要提供了国内最领先的 Seed 系列：

[p012]
* • Doubao-Seed：通用文本/代码模型，和 Coding Plan 里的主力模型同源
  * • Doubao-Seedream：图像生成，Doubao 系图像 SOTA
  * • Doubao-Seedance 2.0：视频生成，全球视频生成领域 SOTA

[p013]
由于 Agent Plan 提供了更为复杂的模型服务，计量方式上引入了 **AFP（ Agent Fuel Points，Agent 燃料值）** 作为统一计量单位。无论调用文本模型、图像生成还是联网搜索，统一用 AFP 计算，每次消耗一目了然。

[p014]
各档位套餐的价格和对应 AFP 额度如下表所示：

[p015]
![Image](assets/%E6%9B%B4%E5%85%A8%E9%9D%A2%E7%9A%84%20Token%20%E5%A5%97%E9%A4%90%E6%9D%A5%E4%BA%86%EF%BC%9AAgent%20Plan-81851f4573/04-image.png)Agent Plan 各档位介绍

[p017]
毕竟 200元 / 月，下手 Agent Plan 之后，马上试着接入我的三个主要应用场景，试试是否使用流畅，大家也可以用来参考一下是否有这些应用场景来决定是否要更换套餐。

[p018]
### 日常工作：编程

[p019]
作为程序员，第一个要试的就是接入工作场景， 编程习惯用 Claude Code，搭配 CC Switch 来管理各种不同的 Coding Plan。因为之前接入过火山的 Coding Plan，所以只需要做简单替换就行：

[p020]
![Image](assets/%E6%9B%B4%E5%85%A8%E9%9D%A2%E7%9A%84%20Token%20%E5%A5%97%E9%A4%90%E6%9D%A5%E4%BA%86%EF%BC%9AAgent%20Plan-81851f4573/05-image.png) cc-swtich 配置 Agent Plan

[p022]
* • 请求地址换成：`https://ark.cn-beijing.volces.com/api/plan`
  * • Api Key 需要在 Agent Plan 页面重新创建，切勿使用 Coding Plan 中配置的（新 ApiKey 在如下图位置，找了很久才找到...）

[p023]
![Image](assets/%E6%9B%B4%E5%85%A8%E9%9D%A2%E7%9A%84%20Token%20%E5%A5%97%E9%A4%90%E6%9D%A5%E4%BA%86%EF%BC%9AAgent%20Plan-81851f4573/06-image.png) 创建 Agent Plan 的Api Key

[p024]
如果第一次配置，那么记得下面的模型也都填一下，推荐使用 `ark-code-latest`

[p025]
![Image](assets/%E6%9B%B4%E5%85%A8%E9%9D%A2%E7%9A%84%20Token%20%E5%A5%97%E9%A4%90%E6%9D%A5%E4%BA%86%EF%BC%9AAgent%20Plan-81851f4573/07-image.png)cc-switch 配置 claude code 使用的模型

[p026]
ark-code-latest 是一个路由模型，在 Agent Plan 后台，可以随时切换要用的模型。从可选模型列表来看，完全覆盖 Coding Plan 能力，支持所有主流国产旗舰模型。

[p027]
![Image](assets/%E6%9B%B4%E5%85%A8%E9%9D%A2%E7%9A%84%20Token%20%E5%A5%97%E9%A4%90%E6%9D%A5%E4%BA%86%EF%BC%9AAgent%20Plan-81851f4573/08-image.png)ark-code-latest 后台的切换模型

[p028]
配置完成后打开 Claude Code ，输入命令 `/model` 验证下配置是否生效

[p029]
![Image](assets/%E6%9B%B4%E5%85%A8%E9%9D%A2%E7%9A%84%20Token%20%E5%A5%97%E9%A4%90%E6%9D%A5%E4%BA%86%EF%BC%9AAgent%20Plan-81851f4573/09-image.png)Claude Code 当前模型查看

[p031]
《纳瓦尔宝典》中提到：真正的财富，是在你睡觉时也能为你赚钱的资产。而“代码与媒体”，则是新时代财务的杠杆！

[p032]
所以，现在除了 Coding 之外，DD琢磨最多的就是如何做好内容媒体，而 Agent Plan 简直就是为这一目标量身定做的！

[p033]
于是乎，第一时间将其配到我的 SoloEnt （专为小说场景优化的编辑器）里，直接用 OpenAI 兼容模式配置：

[p034]
* • BaseUrl 填：`https://ark.cn-beijing.volces.com/api/plan/v3`
  * • Model ID填：`ark-code-latest`

[p035]
于是就可以轻松愉快的写小说了：

[p036]
![Image](assets/%E6%9B%B4%E5%85%A8%E9%9D%A2%E7%9A%84%20Token%20%E5%A5%97%E9%A4%90%E6%9D%A5%E4%BA%86%EF%BC%9AAgent%20Plan-81851f4573/10-image.png)使用 SoloEnt 写小说

[p037]
完成小说这一场景传统的 Coding Plan 也能做到，下面来试试 Agent Plan 中的 Seedance 2.0 来将我们的小说变成视频！先从 SoloEnt 的插件市场里安装这个“Seedance 2.0”视频创作插件：

[p038]
![Image](assets/%E6%9B%B4%E5%85%A8%E9%9D%A2%E7%9A%84%20Token%20%E5%A5%97%E9%A4%90%E6%9D%A5%E4%BA%86%EF%BC%9AAgent%20Plan-81851f4573/11-image.png) SoloEnt 中下载视频创作插件

[p039]
接着继续在刚才的小说工作空间里，直接通过 Chat 的方式给第一章生成视频：

[p040]
![Image](assets/%E6%9B%B4%E5%85%A8%E9%9D%A2%E7%9A%84%20Token%20%E5%A5%97%E9%A4%90%E6%9D%A5%E4%BA%86%EF%BC%9AAgent%20Plan-81851f4573/12-image.png)根据章节生成视频

[p041]
成功加载插件中的Skill之后，SoloEnt一顿操作，根据小说内容，获得生成视频内容需要的场景描述，然后询问调用 Seedance 2.0 需要的 ApiKey：

[p042]
![Image](assets/%E6%9B%B4%E5%85%A8%E9%9D%A2%E7%9A%84%20Token%20%E5%A5%97%E9%A4%90%E6%9D%A5%E4%BA%86%EF%BC%9AAgent%20Plan-81851f4573/13-image.png)填入 你Agent Plan的 Api Key

[p043]
选择第一个，然后输入你的 Agent Plan的专属 ApiKey 之后，就能自动完成视频生成任务的提交：

[p044]
![Image](assets/%E6%9B%B4%E5%85%A8%E9%9D%A2%E7%9A%84%20Token%20%E5%A5%97%E9%A4%90%E6%9D%A5%E4%BA%86%EF%BC%9AAgent%20Plan-81851f4573/14-image.png)视频生成任务提交成功

[p045]
由于视频生成需要一段时间，所以你可以过几分钟之后，通过 Chat 的方式询问任务是否已经完成。在视频生成完成之后，Agent 会将视频下载到桌面，你可以看到具体的路径。

[p046]
![Image](assets/%E6%9B%B4%E5%85%A8%E9%9D%A2%E7%9A%84%20Token%20%E5%A5%97%E9%A4%90%E6%9D%A5%E4%BA%86%EF%BC%9AAgent%20Plan-81851f4573/15-image.png)

### 构建自己的资源池

[p146]
除了编程和内容创作，我还有一个Token消费大头：各种垂直 AI 工具和 Side Project 上的API 调用。

[p147]
订阅了这么多 Plan，使用 Token 的地方也多，最好有一个统一的资源池来管理。于是顺手造了个轮子 OctaFuse（最近刚开源，需要的可以直接去取），把所有购买的 Token 资源都配置进来，对外提供统一的 OpenAI、Anthropic、Gemini 标准接口：

[p148]
![Image](assets/%E6%9B%B4%E5%85%A8%E9%9D%A2%E7%9A%84%20Token%20%E5%A5%97%E9%A4%90%E6%9D%A5%E4%BA%86%EF%BC%9AAgent%20Plan-81851f4573/16-image.png)接入 OctaFuse 管理所有 Coding Plan这样只需要记住一个 BaseUrl 和 ApiKey，就能接入各种工具或自己在开发的 SaaS。如果你也有类似需求，可以试试把 Coding Plan、Agent Plan 都整合进来，省去多账户跳来跳去的麻烦。

[p150]
现在日常工作几乎已经跟 AI 密不可分，对 Token 的需求也越来越大。之前的 Coding Plan 只能满足一部分需求，而火山方舟这次推出的 Agent Plan 覆盖面非常全：国内各大旗舰 LLM、多模态生成、联网搜索、记忆向量化……几乎 360 度涵盖了目前 AI 所触及的主要应用场景，而且用 AFP 统一计费，账单清晰。

[p151]
如果你跟我一样，Coding Plan 已经不能满足日常需求，不妨试试 Agent Plan。
